## Installation

### iOS (iPhone / iPad)

1. App Store öffnen
2. Nach **„✏️ [App-Name]"** suchen
3. **„Laden"** tippen
4. Mit Face ID / Touch ID oder Apple-Passwort bestätigen

**Direktlink:** ✏️ https://apps.apple.com/...

### Android

1. Google Play Store öffnen
2. Nach **„✏️ [App-Name]"** suchen
3. **„Installieren"** tippen

**Direktlink:** ✏️ https://play.google.com/...

## Erster Start & Login

1. App öffnen
2. E-Mail und Passwort eingeben
3. **„Einloggen"** tippen

> Zugangsdaten erhalten Sie per E-Mail von FlowTecsMedia.

## Benachrichtigungen erlauben

Beim ersten Start fragt die App ob sie Benachrichtigungen senden darf.  
**Empfehlung: Erlauben** – so werden Sie über ✏️ [z.B. neue Anfragen] informiert.

Nachträglich aktivieren:
- **iOS:** Einstellungen → ✏️ [App-Name] → Mitteilungen → Ein
- **Android:** Einstellungen → Apps → ✏️ [App-Name] → Benachrichtigungen → Ein

## App aktualisieren

Die App aktualisiert sich automatisch wenn Sie den Store öffnen.  
Für manuelle Updates:
- **iOS:** App Store → Ihr Profil → Nach unten scrollen → App suchen → „Aktualisieren"
- **Android:** Play Store → Profil → „Apps und Gerät verwalten" → App aktualisieren

---

## Probleme & Lösungen

**App startet nicht**
→ App schließen und neu öffnen
→ Gerät neu starten
→ App deinstallieren und neu installieren

**Kann mich nicht einloggen**
→ Internet-Verbindung prüfen
→ Passwort zurücksetzen über „Passwort vergessen"
→ FlowTecsMedia kontaktieren

**Benachrichtigungen kommen nicht**
→ Benachrichtigungen in den Geräte-Einstellungen prüfen (siehe oben)
